# Creator Portfolio + Media Kit

A static website (HTML, CSS, JavaScript). No build tools needed: open `index.html` in a browser.

## Structure
- `index.html`: page content and layout
- `css/style.css`: colours, fonts and layout (colours are at the top)
- `js/main.js`: the VIDEOS, ROWS and BRANDS lists at the top control the videos and brand chips
- `images/` and `videos/`: media files

## Edit
- Replace "Your Name", `your@email.com` and the `@your-handle` placeholders in `index.html`.
- Videos play inside the phone mockups; add a video by dropping `video-8.mp4` and `images/posters/poster-8.jpg` in, then adding it to `VIDEOS` and `ROWS`.
